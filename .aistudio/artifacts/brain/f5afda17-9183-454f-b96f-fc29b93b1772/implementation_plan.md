# แผนการพัฒนา: เพิ่มปุ่ม Play และระบบแอนิเมชันจำลอง CPU Scheduling ในส่วนที่ 1 (Interactive Sandbox)

พัฒนาชุดปุ่มควบคุมการจำลองการทำงานของ CPU (Playback Engine & Time Stepper) ใน **ส่วนที่ 1 · ตัวจำลองการจัดสรรเวลา CPU (Interactive Sandbox)** โดยวางไว้ที่ตำแหน่งเหนือผังแกนต์ชาร์ต (Gantt Chart) ตามภาพอ้างอิงและคำตอบที่ได้รับจากผู้ใช้งาน

---

## 1. องค์ประกอบ UI และฟังก์ชันของแถบควบคุม (Playback Toolbar)

สร้างแถบควบคุมแบบพรีเมียม วางไว้เหนือผังแกนต์ชาร์ตใน `src/components/GanttChart.tsx` หรือ `src/components/SimulatorSection.tsx`:

1. **ชุดปุ่มควบคุมการเล่น (Playback Stepper Controls)** สไตล์เดียวกับภาพอ้างอิง:
   - **`|<` (Reset / Start)**: ย้อนกลับไปเวลาเริ่มต้น ($t = 0$)
   - **`<` (Step Back)**: ถอยหลังทีละ 1 หน่วยเวลา
   - **`เล่น (Play)` / `หยุด (Pause)`**: ปุ่มหลักสี Indigo เปล่งแสง (Indigo Pill Button) สลับสถานะระหว่าง เล่นอัตโนมัติ และ หยุดชั่วคราว
   - **`>` (Step Forward)**: ก้าวหน้าทีละ 1 หน่วยเวลา
   - **`>|` (End / Makespan)**: ข้ามไปยังเวลาสิ้นสุดทั้งหมด (Makespan)
2. **ปุ่มปรับความเร็วการเล่น (Playback Speed Selector)**:
   - ตัวเลือกความเร็ว: `0.5x` (ช้าลง), `1x` (ความเร็วปกติ 1 หน่วย/วิ), `2x` (เร็วขึ้น)
3. **ตัวแสดงสถานะ CPU แบบเรียลไทม์ (Live CPU Status Indicator)**:
   - มีไฟกะพริบสถานะ (Pulse Dot) สีเขียว/คราม
   - แสดงข้อความสถานะปัจจุบัน เช่น:
     - `CPU กำลังรัน: P1 (ช่วง 0 → 2)`
     - `CPU สถานะ: ว่าง [IDLE]`
     - `CPU สถานะ: ประมวลผลเสร็จสิ้นทุกโปรเซส`
4. **ตัวเลขเวลาจำลองปัจจุบัน (Current Simulation Time)**:
   - แสดงเวลาปัจจุบันเทียบกับเวลารวม: `เวลาจำลอง: 4 / 24 หน่วย`

## 2. ระบบแอนิเมชันและการซิงค์ข้อมูล (Interactive Animation & Sync)

1. **เส้น Scrubber บนผังแกนต์ชาร์ต (Gantt Scrubber Line)**:
   - เพิ่มเส้นบอกตำแหน่งเวลาแนวดิ่งสีขาวพร้อมเงาเรืองแสง (Glow Scrubber Line) เคลื่อนที่ตามแกน $X$ แบบเรียลไทม์ตามค่า `currentTime`
   - ไฮไลต์ Block ของโปรเซสที่กำลังทำงานอยู่ ณ เวลานั้น
2. **การซิงค์กับตาราง Execution Slices**:
   - เมื่อเวลา $t$ เดินหน้า ตาราง "การทำงานแต่ละช่วงและ BT ที่เหลือ" (Execution Slices) จะไฮไลต์แถวของช่วงเวลาปัจจุบันแบบอัตโนมัติ
   - แสดง Burst Time ที่เหลือของแต่ละโปรเซส ณ เสี้ยวเวลานั้นอย่างแม่นยำ
3. **การควบคุมแบบ Interactive**:
   - ผู้ใช้สามารถคลิกที่บล็อกโปรเซสใน Gantt Chart หรือลากเส้น Scrubber เพื่อกระโดดไปยังเวลานั้นได้ทันที
